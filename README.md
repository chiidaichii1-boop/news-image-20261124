One image summing up the world news of Tuesday 24 November 2026, drawn as a
newspaper front page:

- **Huang's back** — Jensen Huang returns as Nvidia CEO, 11 days after
  quitting; Nvidia soars 31%, Nasdaq +6.5%, S&P 500 +4.7%, Dow +3%.
- **U.S. squeezes Iran's last lifeline** — "Operation Economic Outcast"
  sanctions hit $14.7bn of shadow banking; Brent $114.80, blockade day 268.
- **War spills into the Baltic** — Russian ship Sparta II hit by drones off
  Finland; a corvette sunk off Libya; missiles breach Polish airspace.
- **COP31 collapses** — the longest climate summit ever ends with no deal
  in Antalya.
- **24 dead in Banten factory fire** — candy factory blaze in Cikande,
  Serang; ~30 still missing.
- **Sport** — Verstappen wins the Las Vegas GP; Alcaraz takes his maiden
  ATP Finals title.

`draw.py` draws the image (`entry.png`) with Pillow; `main.py` copies it to
`/output/entry.png` using only the standard library, so it runs with no
network and writes identical bytes on every run.
